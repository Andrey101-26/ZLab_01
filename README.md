# toolkit

Консольный набор утилит: калькулятор и конвертер величин.

## Установка

```
pip install -e .
```

## Использование

```
python -m toolkit calc "2 + 3 * 4"
python -m toolkit convert 1000 --from mm --to m
python -m toolkit --help
```

## Возможности

Калькулятор:
- целые и вещественные числа
- операции + - * /
- унарный + и -
- пробелы игнорируются
- приоритет * и / над + и -

Конвертер:
- длина: mm, cm, m, km
- масса: g, kg
- температура: c, f, k
- регистр не важен
- между разными группами нельзя
- ниже абсолютного нуля нельзя

## Коды возврата

0 — успех
2 — ошибка пользователя
